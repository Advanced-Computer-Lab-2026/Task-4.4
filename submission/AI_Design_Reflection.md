# AI Design Reflection

One initial suggestion was to change the search and filter controls to remove **Apply** and present them as live filters. On inspecting the implementation, the search text and dropdowns already update the results immediately; **Apply** only displays a report count. Changing this behavior was less valuable than the validation, recovery-status, and empty-results issues selected for this rescue. The live-filter redesign was therefore rejected and not included in the three implemented improvements.

The implementation instead focuses on field-specific validation messages, clear per-item collection status, and a useful no-results recovery action. It also adds separate lost/found report shortcuts that preselect the status, a **My listings** view for reports owned by the signed-in user, visible edit controls on those reports, and a two-step delete action at the far left of the edit form's action row. The first delete click opens a danger confirmation popup away from Save and Go back. To make Lost, Found, and Claimed cards easier to distinguish at a glance, each card now has an icon-and-text status badge and matching colored top edge. The existing live search and category/status filtering behavior is preserved.
